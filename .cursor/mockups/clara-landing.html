📄 Lee tus extractos

🎙️ Notas de voz

🔄 Open Banking

Sincronización segura

Conexión solo lectura con tu banco. Clara matchea movimientos contra plantillas y nunca tiene acceso a tu dinero.

📅 Mes a mes

Plantillas + copia mensual

Una plantilla define un gasto recurrente. Cada mes tiene su copia que tildás cuando lo pagás. Sin sorpresas.

🏦 Multi-banco

🤝 MCP para tu AI

Claude · Cursor · ChatGPT

Clara expone un servidor MCP. Tu propio asistente puede consultar y actualizar tus finanzas con tu permiso.

MCP-ready

Tu propio AI puede
hablar con Clara.

Clara expone un servidor MCP (Model Context Protocol). Generás un token desde Settings y lo pegás en Claude Desktop, Cursor o cualquier cliente compatible: tu asistente consulta tus meses, mira el balance y registra gastos con tu permiso.

Cómo conectarlo MCP público 
{
  "mcpServers": {
    "clara": {
      "url": "https://clara.app/api/mcp/user",
      "headers": {
        "Authorization": "Bearer ada_pat_…"
      }
    }
  }
}
